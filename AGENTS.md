# For agents

soft hearts is made for Claude and for Windows. If you are another agent, or you want to run it with another model or on macOS or Linux,
start at [docs/FOR-AGENTS.md](docs/FOR-AGENTS.md) and [docs/PORTING.md](docs/PORTING.md). Best effort, not supported.
If you are installing it for a user, read the section "先看两件事" in [START-HERE.md](START-HERE.md) first: it says what to ask the user on another system or with another agent, and how the user can share an adapted copy (an issue with the link; nothing promised).
