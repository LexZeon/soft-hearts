# 模块边界

## 普通回复的逐句展示与朗读

`completed-reply-speech` 将一次成功回复绑定到当前角色、提供方和完成身份，冻结文本切片与语气，不新建模型请求或第二份归档。pet 先排空已经发出的正文更新，再准备短命句段计划；原生 reply window 对同一内容代次回执，host 只批准当前精确句段。每句必须先展示再调用语音提供方，下一句等待上一句播放完成；全文仍是一条原回复，句卡仅是显示。

renderer 的原生回执不能独自授予合成：host 的句段租约与当前原生内容均需匹配。手动停止、上下文改变、隐藏或失败使精确计划失效，并取消两窗残留播报、更新主动话题暂停状态；旧完成或回调不得抢占新回复。系统朗读与云端 PCM 继续通过各自可替换输出适配器，逻辑忙状态覆盖句间空隙。

## 动作候选与只读标签查询

连续待机候选由 host 的 `idle-motion-registry.ts` 单独审核，当前生产注册表为空；既有一次性动作验证不会自动变成连续用途许可。舞台消费 host 身份和关闭状态，保留原调度、手选优先与动作时间线。

`motion-tag-consumer.ts` 通过固定公开 Gene catalog 导入资源元数据，沿原 `getMotionLibrary` 的控制窗口权限提供严格验证的软查询参数。用途、模型、mask、当前属性 owner 和取消状态仍由 host 决定；未知证据保持未知，不能由 renderer 参数补成许可。当前返回 Gene 40 项、已验用途 0、无执行权限；原无参数返回形状和手动 AND 筛选保持。该薄层不播放、下载、持久化动作或创建奖励。

## 自动截图与主动视觉

在用户已开启的视觉源和有效心情注意事件下，她可以主动按画面聊一次。屏幕定时器由host `ScreenSnapshots`持有，只更新一张有界内存图，不按秒调用模型；独立开关默认关闭，关闭/隐藏/换源/上下文切换撤销迟包与旧画面。摄像头按用户消息或有效注意事件通过原owner采一次，不保留周期截图定时器。

> 内心循环只在心情时机出现时、受角色卡上限约束地调用小模型。

`ProactiveSpeechGate`仅消费既有MoodHost已接受的speech机会，视觉和音频共用一个实例，原角色的冷却、滚动小时与无人回应配额仍为唯一预算。`ProactiveVision`负责一次采样、一次有界无工具生成、实际append确认、同作用域文字归档；用户输入、互动或切换优先取消。主动文字保留来源与主动身份、单assistant归档、权重0并排除自动长期召回，不伪造用户发言，不因渲染/采样增加奖励。原屏幕文字是观察数据，不能授予任务或执行权限。

## 独立局部物理

已交付稳定源的 `shared/model-physics.ts` 与 `electron/model-physics-settings.ts` 定义独立、默认关闭的头发/胸部开关和强度、共享质量档；host 固定 sidecar 原子保存后广播，只有控制窗主 frame 可写。该数据不进入旧 AppSettings 或便携卡，旧完整版重写原设置仍保留物理选项。预览只报告结构支持，透明桌宠按可见性与有效开关惰性加载固定离线 Ammo。

`physics-rig.ts` 从真实权重、骨架祖先、锚点与约束闭包选择局部动态体和必要静态/运动学碰撞体，保护头脸/躯干/根骨，不改源 PMX。`model-physics.ts` 为两部位分别拥有世界与全部显式分配；质量决定调度/实际迭代预算，强度只缩放有界输出。每帧先恢复最外物理，再恢复并合成原动作/互动/显示桥接，最后附加局部物理；零时间重附不推进时钟。关闭短退场，隐藏/换模/销毁立即恢复释放，恢复不补积压；两世界间不承诺动态互碰。

`ammo-runtime.ts` 固定 Three r170 JS/WASM 与 SHA-256，资源校验覆盖包内发射和完整 Ammo/Bullet 通知；CSP 只增加本地 WASM 所需项。诊断分别报告 owned 对象平衡与保留的 WASM 容量，不能把容量称作活对象/RSS 或声称卸载。

## 试验心情、直接输入与私人文字记忆

`shared/mood.ts` 提供确定性规则，`electron/mood.ts` 统一持有按角色隔离的参数/状态及节流保存。`shared/mood-runtime.ts` 定义有界观测和输入；renderer 只能向 pet 专用 IPC 报当前 token/session 的接触阶段、新增有效时间或一次点心接受，没有任意通道 delta、路径或系统能力入口。模型/角色/显示生命周期使旧输入代次失效，开发者模式只观察和调整参数，不赋执行权。`src/ui/PetInteraction.ts` / `MoodCompanion.ts` 负责真实鼠标质量、准备/释放、局部连续反馈及串行输入；`MmdStage` 通过独立 `mood-feedback.ts` 叠加后恢复，不改原 VMD 和时间线。重复 morph 偏移仅记录首次底值。

本地2000ms驻留：`rua-hover`只报告渐进注意，未创建host互动session或奖励；满门槛后从当前真实点计量，等待的鼠标运动不补算。定时复核当前头皮/UI几何只决定驻留是否仍有效，不创造手速。注意权重与头部视线平滑交接，享受眼睑与自然眨眼合成一次；准备喂食使用独立有界开闭嘴，手选口部优先，说话幅度不变。

完整开发者观察区位于控制窗内容列的正常文档流，pet只留不覆盖角色的紧凑入口。原工具栏/聊天节点按注意进度渐隐/恢复，保留草稿和实际UI保留区。控制窗的六项本次运行手感经固定窄 `BroadcastChannel` 给pet，严格字段/角色/token校验、有界请求与去重，收到实际应用确认才报告成功，超时/销毁/代次变化明确失败；消息不获得host、文件或持久化能力。独立回答窗口的透明度是另一条有界显示补丁，不改变正文、朗读完成或五秒期限。

## 可拆除的预装表现映射

`shared/behavior-motion.ts`集中语义目录、明确fallback和纯选择器。`electron/behavior-motion.ts`持有短命状态/反应意图；状态键只随离散意义变化，普通快照/数值漂移不重开。关闭/接触期间也消费R，新会话在异步归档前清旧R，迟到取消只匹配其源事件。`MoodView.behavior`是可选只读输出，不进卡、状态存档或记忆，不调用第二次奖励。

`electron/behavior-motion-bindings.ts`将11个固定`face.*`身份解析到Gene原片/hash/时长；专用IPC仅接受当前cue ID/token，解析、文件授权与URL注册后都复核当前身份，不接受renderer资源ID、路径或外部URL。`src/stage/behavior-motion.ts`只采已审的眉眼morph，排除骨骼、口部、自然blink、红脸和复合morph；原口型、因果红晕、真实跟手与音频律动继续各自运行。源片单次按原时间推进并淡出后回程序fallback，没有hold/loop或持久自动动作选择；上身动作委派原有唯一上身播放器，不复制另一套上身系统。

stage只接统一生命周期和现有窗口/相机/IME/穿透/本地预览门控。帧外取消也先恢复最外显示桥接，再更新内层并以`frame(0)`重建当前桥接目标，避免两tick间停层残留；零尺寸也清理旧反应。

`electron/companion.ts` 在角色/提供方上下文、用户请求、自然回复和记忆之间建立串行边界。`electron/memory.ts` / `shared/memory.ts` 维护私有追加日志、段级标题/tags与有界分页/召回；记录不含图像、声音或素材路径。所有 scope 均由 host 决定，renderer 无跨角色或跨提供方读写参数。角色卡 v2 可携完整版本化参数模板，运行状态与私人经历不随卡导出；旧角色先迁移已保存调校，模板变化不重置会话和当前值。新对话、删除记忆、重置应用设置是不同操作。切换和删除同步清理活动会话与旧界面副本，迟到片段不能重建删除记录。退出等待已产生文字的收尾与写入队列。

`procedural-blush.ts` 把短暂脸红包络映射到已确认归属的真实 skinned 脸部材质，使用头部局部双颊 mask 作 shader 贴色。旧渐变面片曾被脸面遮挡，已弃用；当前不创建红晕面片、不整模型染色。保留原材质的 UV、alpha、深度、光照和贴图，clone 共享原 Texture 以保留迟到加载配置。顶点在 morph/skinning 后取局部坐标，`onBeforeRender` 使用最终骨骼姿态的 mesh→head 矩阵。程序路径与经核查的单个正向 morph 备选单选；材质/编译接点不支持时降级，手选表情优先，尺寸与红度独立。

眼骨 E 保留为稳定坐标与校准单位；只有确认主眼材质的左右分离、投影面积、截尾边界及原皮肤归属可靠时，才用显示眼距 V 布局双颊。嘴部纵向比例另估，缺嘴骨明确标注估算，不随扩大横距直接同比放大。校准从静止参考姿态采样后完整恢复当前骨骼/morph。五项本机定位数据由 `BlushCalibrationStore` 按模型内容 SHA-256 独立保存；IPC 写入只允许控制窗与当前已验证模型，旧 URL/哈希回包不能污染新模型。局部预览约三秒，不保存或产生状态事件，生命周期结束清理。`head-contact.ts` 独立拟合眼线上方、实际发顶范围的头皮椭圆；`PetInteraction` 保留原手速参考宽 W 与喂食嘴点/半径，👋 仅为不拦截输入的 DOM 光标装饰。

`mood-chat.ts` 处理同一次正常回复的可选、随机标记、有界状态尾注；尾注不显示或归入原文，置信度/格式失败无语义注入。接受用户消息与完成后的 appraisal 分开去重，系统检索和角色自言自语不产生人类回应或旧奖励。当前以本地摘录/词表生成标题和 tags，无额外模型调用、向量库或后台反思。

## 聊天的短暂上身手势

同一可选尾注允许 `gesture:none/explain/upbeat/consider`；缺字段兼容为 none。`shared/chat-gesture.ts` 结合已接受回复、主/伴感受、趋势及角色姿态强度做确定性选择；`electron/mood.ts` 在归档/交付成功且角色/模型代次仍有效后发一个短命 cue。该层不再结算心情或用户回应，不增加模型调用，也不持久化动作选择。含 none 的已处理请求有界去重；停止、新消息、新对话、直接互动、暂停、隐藏及角色/模型/提供方切换使旧表现失效，迟到取消不能清掉另一轮 cue。

`resolveChatGesture(cueId, token)` 只接受当前 cue 身份。`electron/chat-gesture.ts` 固定映射到两段已审核的本地资源：GENEA `speaking-gesture-2`（说明/克制）与 MPI `conversation-joy`（积极强调），复核目录、许可、字节/哈希；主进程在解析和授权素材前后检查代次后返回受限 URL，不给 renderer 本机路径、任意 pack/path/URL 或下载入口。两个窗口消费同一 host cue，各自舞台在加载前即记为已消费，冲突/失败/失效后不补播。原始资源与手选动作配置不变。

`src/stage/chat-gesture.ts` 的 `ChatGesturePlayer` 保留原 MMD 插值工厂，仅对白名单胸、肩、臂、肘、腕四元数在当前基础姿态与样本之间作有界 slerp，强度上限 0.7，正常单次显现/退场默认 250/450ms；头脸嘴、根腿及位移不进入自动层。加入新脸部映射后，每帧按 `motionTransition.restore → behavior.restore → player.restore → stage.restoreLayers → MMD helper.update → idle → player.frame → mood → music → behavior.frame → motionTransition.frame → render` 合成，原基础 mixer/Action 持续前进；无 VMD 时先建立放松双臂底姿，结束后恢复，不累积旋转。手选 gesture 或其它动态上身 pose 优先；预装 Stand 的约 2° 胸部动态由 `default-pose.ts` 以目录字节数与 SHA-256 确认为允许的背景，不能仅凭文件名放行其它资源。

`motion-transition.ts` 只桥接同一模型的实际受影响属性，从换绑前显示姿态在400ms内渐向每帧继续评估的新目标；不创建第二套Action/mixer、不改原插值或未改通道phase。快速重选从当时显示接续，启动时`frame(0)`防同一事件循环暴露未混合目标，隐藏/代次/销毁不补播。已显示模型的资格独立于帧计时：设置重复通知可见会重置计时，但不能令快速缓存动作跳过桥接；真实render建立资格，模型清理/实际不可见撤销。清空动作以真实idle为目标且保留helper时钟；待机臂姿由已commit通道判定，尚在加载的新设置不能提前改旧动作。音乐关闭等路径必须先恢复最外显示桥接再恢复内层，防缓存重复叠加。

这两段自动上身 overlay 只用于预装的 Gene + Stand 与指定的 Happy expression/取消组合；全库的离散采样、原始完整 VMD 的循环和其它模型不因此获得同样的用途。

## 回答浮窗与任务

`electron/reply-window.ts` / `reply-layout.ts` / `reply-lifetime.ts` 管有界静态回答表面、跨桌宠窗口的几何位置与五秒生命周期；`reply-preload.ts` 不暴露应用 IPC。舞台只报告近似嘴部投影和头部避让半径，`PetUI` 发显示更新。独立窗口不持有模型、媒体或提供方权限；移动与置顶跟随主人窗口，隐藏与退出清理。`HoverVisibility` 独立控制工具栏的一秒离开计时。

`shared/codex-tasks.ts` 定义任务契约与本地建议，`electron/claude-tasks/` 另起一个任务进程（默认关闭，用户选定一个文件夹后才可用；读文件自动放行，写文件和运行命令每次都要用户批准），`src/ui/CodexTasks.ts` 显示自己的任务历史、显式范围和单次审批。任务与内存陪伴聊天分离，不继承后者的人设/画面，也不向后者赋执行权；陪伴聊天本身始终不带工具。任务索引只在私有配置内；关闭自己的连接、停止或重载界面均不能留下无人监管的工作。后续电脑操作须新增可验证、独立确认的工具适配，不模拟第一方客户端或复用隐藏账户管道。


首版用 Electron 提供桌面能力，用 TypeScript 与 Three.js 实现界面和 MMD 舞台。保持单个应用、少量明确模块，不引入插件容器、消息队列或内置推理框架。

聊天、图片理解和任务使用用户本机已登录的 Claude Code（命令行）。朗读支持免费的系统音色与用户显式配置的可选百炼情感 TTS，语音输入默认使用应用自带的本机识别。不能把登录状态视为音频 API 授权。

控制窗口与透明桌宠窗口共享配置，各自拥有舞台实例。相机构图与桌宠缩放保存在设置中；舞台同时接受原生窗口可见性和网页可见性事件，隐藏后停止动画帧，隐藏控制窗口还会卸载预览模型，重开时恢复。渲染性能主要取决于模型面数、材质数、顶点变形和纹理分辨率，降低帧率不能消除大模型占用的显存。

聊天与 agent 任务分开：聊天只负责回复；agent 入口由用户选择工作目录并显式提交。两个窗口展示同一段内存聊天，主进程先接受唯一聊天请求，再通过 `onChatStarted` 发布已接受的请求、文字上下文和窗口所有者；后续聊天事件向两个可信窗口按主进程顺序发送。界面不以另一个窗口的乐观提交覆盖已接受请求，拒绝并发提交不能清除正在回复的消息。agent 事件仍只发给提交窗口，TTS 仅由聊天所有者触发；跨窗口状态恢复、清空和停止不赋予对方 agent 的执行或取消权限。图片只用于当前请求，不进入文字历史；关闭共享会丢弃共享画面、取消相关请求并清除旧视觉对话。切换供应商不应改变桌宠舞台，也不能沿用旧对话或连接密钥。

镜头输入默认关闭，用户在控制窗口或桌宠工具栏进入调整模式。左键按住旋转，右键按住沿画面平移，滚轮调整距离；W/S 沿视线前后移动，A/D 沿镜头水平轴移动，Shift 沿世界坐标向上、Z 向下。键盘移动按秒计算并归一化，Shift 不改变左键映射。配置保留目标点 XYZ，兼容旧配置缺少 Z 时取零；全身与近景预设重置 Z。键盘只在画布有焦点时生效；画布失焦清除按键和捕获，窗口失焦、隐藏、Esc 或完成按钮退出模式。

桌宠普通画布不承担窗口拖动。只有按住悬浮工具栏的窗口移动按钮才发送受限位移 IPC，松开、取消或失焦即释放指针；悬浮工具栏同时显示当前窗口尺寸。聊天回答采用可滚动圆角气泡，尾部使用舞台约 10 Hz 提供的头部附近投影点；这是骨骼偏移估计，缺少头骨或投影不可见时使用布局回退，不代表逐像素嘴唇定位或音素同步。

屏幕共享、摄像头共享和语音输入是本次运行的显式开关，重启默认关闭，不能从保存的 ASR 地址或声音配置推断设备授权。屏幕共享在发送聊天时截取桌宠所在屏幕；摄像头所有者窗口维持无音频的视频流，每秒最多发布一张不超过 1280×720 的 JPEG。主进程只保留最新且未过期的一帧；关闭、转移所有权或设备失败会停止对应采集并清除画面。手动附加单帧照片继续使用独立的临时权限与资源回收路径。

麦克风仅在所属窗口明确开启语音输入后获取，使用 Web Audio 的静音输出处理 PCM。RMS 分段器丢弃短噪声，以至少 250 ms 的有声内容和约 650 ms 静音确定一句，最长 15 秒；转为 16 kHz、单声道、16-bit WAV 后交给主进程的兼容转写接口。单个转写请求期间不排队录音，播放回复语音时暂停分段并清空缓冲，结束后保留短暂尾音保护。关闭、转移所有权或释放窗口时停止轨道、断开节点、关闭音频上下文并丢弃晚到结果。麦克风和摄像头轨道的 `ended` 事件也触发对应关闭路径；主动停止先移除监听器，旧所有权的晚到回调不能关闭新会话。应用不附带识别模型，也不自动启动模型服务。

VMD 动作与程序化呼吸、视线需要遵循“恢复基础姿态 → 更新动作 → 叠加微动作”的顺序。更换模型、动作或关闭窗口时释放旧资源，避免多次加载后增长的纹理与动画实例。

显式动作分为身体姿态、手势、表情三个通道。旧 `motion` 保留为身体资源；可选 `motionLayers` 保存手势与表情，缺省时仍按旧整段 VMD 播放。首次分开时保留原动作的表情来源，后续修改只更新所选通道。`LayeredMmdAnimation` 在同一个 MMD mixer 内按属性分配轨道：表情使用 morph 与眼、嘴等面部骨骼，手势使用上身、头颈及手指，身体使用其余骨骼及没有被手势占用的上身轨道。重叠属性由手势覆盖，不取平均；未修改通道保留 Action 与进度。同步 Three r170 的骨骼备份以防解绑后旧姿态恢复，不改源文件或时长。

系统声音律动是运行期手动开关，只允许可信桌宠主框架开启 Windows loopback。Chromium 的 display media 请求需要视频兼容轨，主进程只提供桌宠自身窗口，渲染器立即停止该轨，不枚举屏幕、读取画面或放宽麦克风权限。音轨只在本机以 30Hz 提取 RMS 与频段能量，既不录制也不交给聊天。`MusicDance` 根据鼓点强弱、频段比例及近期能量变化生成有界身体偏移；每帧恢复基础后叠加，表情与手势资源继续播放。隐藏、退出、提供方改变或采集结束均撤销授权并释放音轨、AudioContext 与帧循环；静音和采样中断平滑回零。

可选百炼 TTS 使用主进程 `SpeechRuntime` / `tts.ts` 调用用户控制台 Host 的原生 HTTP SSE 接口，不接收渲染器任意配置或音频 URL。`ttsApiKeyEncrypted` 与现有连接密钥分开保存，公开设置只返回脱敏值；换 Host 或地域不能复用旧 Key。`styleBindings` 按角色 ID 与模型路径精确匹配，仅覆盖音色、情绪指令和语速，不改变连接或资源授权；公共默认风格中性，个人角色设定不写入软件默认。

`VoiceOutput` 统一系统语音和云端播放。PCM16/24kHz/mono 片段由 `StreamingVoicePlayer` 顺序调度，处理跨包半个采样、取消、迟到事件与资源回收；只有最后音源结束才完成朗读 Promise。网络传输完成后仍保留不含密钥的接收者标识，以便新窗口播放能取消旧窗口剩余 PCM。文字沿用产品最多 6000 UTF-16 单位，分句为每次最多 2000；单个请求超时 120 秒、音频最多 16MiB，播放器会对过长会话明确报错。首音频包指标取发起请求至首个非空 PCM；开始播放指标来自浏览器调度与输出延迟估计，均不能等同物理扬声器测量。原生参数依据 [官方 HTTP API](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)。

鼠标视线先按鼠标与眼睛屏幕投影之间的距离平滑分配眼球与头部权重；近处以眼球为主，远处增加头部比例，眼球响应稍快，头部稍慢。优先驱动左右眼骨，避免同时叠加两眼控制骨造成重复旋转；缺少眼骨时退回有角度上限的头部视线。所有偏移叠加到当前姿态，并在下一帧恢复，不积累旋转或改写 VMD。

预装资源只包含 Gene 模型、必要贴图、40 动作和授权文档，按 `assets/bundled/mmdagent-ex/gene/<revision>/` 随源码 ZIP 与 asar 分发。`BundledAssets` 校验固定清单、哈希和目录范围，只授权模型/贴图目录及选中的动作目录。只有不存在 `settings.json` 的新配置才自动选用 Gene 和 Stand；已有配置，包括主动清空的选择，保持原样。显式「使用预装 Gene」恢复预装选择并保留其它设置；重置设置恢复 Gene 默认值。

持久动作切换通过用户点击和窄 IPC 进行，不由聊天或 agent 改写，不接收任意 URL 或文件路径。上文聊天 cue 仅使用另行固定的两资源瞬态白名单，不扩大手选动作入口。预装模式校验本地资源并返回引用，不联网、不拷贝用户缓存；损坏时明确报错。原下载器保留为独立测试/维护边界，但预装 UI 不自动降级到联网下载。注册和持久化前后复核操作代次，过期结果恢复旧动作；UI 先提交待保存设置再启用，避免旧空动作保存覆盖新结果。构建和打包前校验全部公开资源及许可文件，拒绝未列入清单的附加文件。

VMD 解析适配器只在内存中处理上游 `normal.vmd` 模型名字段截断的 Shift-JIS 尾字节，不改写磁盘文件、哈希、骨骼名或表情名。下载与播放是独立边界；分类与 tags 仅为资源检索元数据，不构成自动行为系统。

心情、rua 与普通点心通过独立状态/行为事件接入舞台。更多闲置动作与互动按需要迭代，不把状态规则写进聊天提供商；设计文档不扩大运行权限。

角色卡启用或修改当前人设会结束旧对话；开场白显示在两个窗口，并作为新会话的助手首句。卡片状态带单调修订号，旧回包不能回滚新选择；跨窗口历史恢复只接受启动时的一次匹配上下文快照，角色切换、新对话和聊天开始后不再接受迟到快照。通用设置保存使用资源基线保护，旧的空模型/动作快照不能清除刚由角色卡或原生选择器启用的资源。角色卡不会改动聊天提供方、密钥、共享状态或 agent 权限。
