# 新电脑试装测试方案

在一台**从没装过 soft hearts 的 Windows x64 电脑**上，按新用户的路子装一遍、用一遍。一次测三件事：x64 能不能用；第一次下载、安装的体验；README、START-HERE 和发布说明里说的每一句，在新电脑上是不是真的。

分四个阶段，**顺序不能换**：第 1 阶段必须"盲测"，在它之前不给那台电脑上的 Claude 看这份清单，也不额外指点。

## 测之前，用户在那台电脑上要准备的

- 装好 Claude Code 并登录（Windows 上的 Claude Code 需要 Git for Windows，一起装好）。
- 不要事先装 Node.js，不要事先下载 soft hearts。
- 记一下开始时间。
- 用公开仓库 `https://github.com/LexZeon/soft-hearts` 测，不用登录 GitHub。公开仓库里有了发布版（用户说"上传"之后）才能测。
- 不要把令牌、密码、验证码贴进对话。

## 第 1 阶段：一句话部署（盲测）

在 Claude Code 里**只发这一句**，不加别的说明：

> https://github.com/LexZeon/soft-hearts 帮我安装并启动 soft hearts

接下来像普通新用户一样：它问什么就照常回答（权限弹窗按常理点"允许"；问偏好时可以不回答，看它会不会用默认值）。不要提示它去看哪个文件、用什么命令。

用户自己记（不用很精确）：

1. 从发出这句话到**她出现在桌面上**用了多久，到**她回你第一句话**用了多久。
2. 中间它**问了你几次**、各问的什么（权限弹窗也算，大概数一下就行）。
3. 有没有哪一步卡住、报错、要你自己去做什么。
4. 它有没有主动介绍功能、问你一两个偏好。
4b. 装好、她回过话以后，它有没有原样说出 START-HERE 第 7 步里创作者的那句话（中文对话说中文那句，英文对话说英文那句），而且只说了一次。
5. 你的感受：顺不顺、哪里让你犹豫或看不懂。

## 第 2 阶段：逐项核对（这时再给它看清单）

在**同一个** Claude Code 对话里，粘贴下面这段（这一段可以直接粘贴）：

> 刚才的安装是一次新用户测试。请读源码里的 docs/fresh-machine-check.md，按"第 2 阶段"逐项核对并记录，然后按"报告格式"写报告。只做清单里写的事。

它要核对、记录的：

- **环境**：Windows 版本和架构（应为 x64）；`Get-ExecutionPolicy -List`（只读，不要改）；源码放在哪个路径；`claude --version`；是否已登录（只记是/否）。
- **安装结果**：Node 是不是下载了 **win-x64** 版并通过校验（看 `.local\runtime`）；Electron 是不是 x64；类型检查、构建是否通过；安装用了多久。
- **写到了哪些地方**：项目文件夹里的 `.local`；`%APPDATA%\soft-hearts-claude-dev`；pnpm 缓存（`%LOCALAPPDATA%\pnpm`）；有没有在别处留东西；系统 PATH 和执行策略是否没变。
- **她**：桌宠窗口里看不看得见 Gene；第一次启动控制窗口是不是收起的；回复是否正常。
- **内部通道**（README 里"让自己的 Claude 帮忙换角色、调设置"那几句）：
  1. 在终端运行 `claude mcp list`，看有没有 `soft-hearts-next-dev`（源码版登记的名字）。
  2. **新开一个** Claude Code 对话，请它用 soft hearts 的内部通道依次：看现在的状态（`get_status`，有 `get_her_state` 的话也看看她现在怎么样）；把朗读音量调到 40 再撤回；让她挥一下手；有"她主动找你说话"这个设置的话调成"少一点"再撤回。逐条记成没成功、它怎么说的。
  3. 打开控制窗口的「隐私与设置」→「Claude 内部通道」，看说明和开关能不能看懂（不用关掉）。
- **第二天怎么再打开她**：从托盘退出，再假装自己是新用户，看看怎么再把她打开（文件夹里双击 `start-soft-hearts.cmd`？桌面上有没有快捷方式？），记下是否一看就知道。

## 第 3 阶段：下载压缩包这条路

1. 从托盘退出第 1 阶段装的那只。
2. 在浏览器里打开仓库页面，Code → Download ZIP。**不要**先解除锁定，直接用资源管理器解压到一个短路径（比如 `C:\sh-zip`）。
3. 双击 `start-soft-hearts.cmd`，记下：Windows 有没有先弹安全提示；脚本有没有说明文件"来自网络"、问 Y/N；按 Y 之后能不能装好、启动、回话；一共用了多久。

## 第 4 阶段（可选，耗时长）：桌面上的开发版

在第 1 阶段的源码文件夹里打开终端，运行 `start-soft-hearts.cmd desktop`，记下耗时、是否成功、桌面上出现了哪个快捷方式、从快捷方式打开是否正常。

## 测完收拾（可选）

不想留在那台电脑上的话：从托盘退出；删掉两个源码文件夹；删掉 `%APPDATA%\soft-hearts-claude-dev`；在终端运行 `claude mcp remove soft-hearts-next-dev -s user`；桌面上如果有 soft hearts 的快捷方式也删掉。

## 规则（给帮忙的 Claude Code）

- 按 `START-HERE.md` 的要求做：不改系统的执行策略、不用 Bypass、不读登录凭据、失败时保留原始错误。
- 只用预装的 Gene，不加载私人模型；不打开屏幕、摄像头、麦克风。
- 报告里只写步骤、结果、耗时和报错原文；不贴截图，不写聊天内容，不写账号、令牌或任何密钥。
- 真实聊天只发清单里写到的几条短消息。

## 报告格式

一份中文 Markdown，标题"新电脑试装报告 <日期>"：

1. 第 1 阶段：用户记的 5 点（这几点由用户口述，照记）。
2. 第 2～4 阶段：每项一行，✅ / ❌ / 没做，耗时，报错原文（如果有）。
3. 最后一段："新用户最可能卡住或犹豫的地方"，按严重程度排。

写好后交给用户，用户转给开发这边的 Claude。
