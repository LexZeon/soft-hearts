# 怎么摸她的头、捏她的脸、喂她零食、牵她的手、拉她

这几样都在桌宠窗口里，用鼠标直接对她做，没有设置页里的开关或按钮要点（所以"入口"就是她身上的位置）。每一样她的反应都不固定：按她此刻的心情和性格挑，同一件事做两次不会一模一样。以下写法对照当前界面代码核对过（摸头、捏脸、喂食的判定在 `src/mood/PetInteraction.ts` 和 `CheekPinch.ts`，牵手在 `src/stage/hands-stage.ts`，拉她在 `src/mood/pet-pull.ts`、`shared/behaviors/pull/`）。

前提：她在桌面上看得见（桌宠窗口没有隐藏）。开了"鼠标穿透"时，她的身体照样能摸、能捏、能喂。

## 摸头：鼠标放到头顶，来回轻轻划，不用点

- 位置：她的头顶（从眼线往上到头顶的那一块）。
- 怎么做：把鼠标移到头顶上，光标会变成 👋；在头顶上来回轻轻划动。**不用按键，鼠标停在头上也不算，要有来回的小幅移动。**
- 速度：不要太慢也不要猛甩。划得很慢、停下超过四分之一秒、或甩得很快，那一段不算。
- 效果：她享受地被摸，心情和亲近感上升；连着摸会越来越没新鲜感（"腻"），过几分钟恢复。鼠标移出头顶或离开窗口就停了。摸的时候她的气泡会暂时淡出，摸完再回来。

## 捏脸：在脸颊上按住左键，来回拖一小下

- 位置：她的左脸或右脸颊（两侧脸颊）。
- 怎么做：鼠标移到脸颊上，光标变成 👉；**按住鼠标左键**，光标变成 🤏，按着轻轻来回拖几下，松开结束。只有鼠标左键、只有鼠标（触屏不算）。
- 效果：她被捏脸，有反应，可能脸红；同样会"腻"。

## 喂零食：把一张图片拖到她嘴边，等她张嘴再松手

喂的是一张**图片**（点心的照片或图），不是设置里的东西，没有按钮。

1. 在文件夹（资源管理器）里选**一张**图片文件：PNG、JPEG、WebP、GIF 或 BMP，不超过 50 MB。一次只能一张。
2. 按住这张图片，**拖到桌宠窗口里她的嘴边**。
3. 在嘴边**稍停一会儿（约 0.65 秒）**，她会张开嘴准备（靠得越近张得越大，正在朗读的话会先停下来，轻轻"啊"一声）。
4. 她张好嘴之后**松开鼠标**，才算喂到：她咬下去，"嗯"一声，嚼一下，然后接着说刚才的话。
- 没到嘴边就松手、嘴还没张开就松手、拖的不是单张图片，都不算喂到，会提示"请在嘴边稍停，张嘴准备后再松开鼠标"。
- 她认出点心是什么：控制窗口「隐私与设置」里有开关"喂食时让她认出是什么"，默认开着。开着时，喂到的那一口的缩小图会交给你自己的 Claude 看一眼，她会按口味和性格说一句；关掉她照样吃，只是不认图。这个开关不需要改，想喂就直接喂。
- 开着"允许记录"时，喂过什么会存进控制窗口「记忆」里的"我们的小东西"。

## 牵手：鼠标停在她手边，她伸手，点一下

- 怎么做：鼠标在她身边够得着的地方停一会儿（约 2.5 到 4.5 秒，每次不一样），她可能把手伸过来找你的鼠标；光标移到她手上变成 🤝，**点一下**就牵上，牵着时手跟着鼠标走。她想亲近你或有点怕的时候，也会自己先伸手。
- 她不一定每次都伸手，这是她自己的决定，不是按钮。困的时候握得松。
- 还有两个类似的小互动：说了带时间的打算时她伸小指拉钩（光标 🤙，点一下）；猜拳分出胜负、或你说"做完了"时她举手击掌（🙌，点一下）。

## 拉她：按住她的手、身体、头或腿，拖

- 位置：她的手和胳膊、身体（肩、胸、腰、裙子）、头（头发算头）、腿和脚。脸颊不算（脸颊是捏脸）。
- 怎么做：在她身上**按住鼠标左键，拖一段**（挪过大约 8 个像素，或按住超过约半秒才算开始；很快点一下仍只是点）。松手她慢慢回来，Esc 也能取消。
- 桌宠里：拉手或胳膊，手臂朝你拉的方向伸、上身跟着倾一点；拉身体，腰以上倾，脚不动；拉头，头和脖子小转；拉腿或脚，膝盖轻轻往外摆，脚不动。拖得再远样子也不再变大，只算"更用力"。
- Unbound 里：拉身体或手往旁边，她迈步跟过来（不比平时走路快，只左右），松手就站在那，之后至少 5 分钟不自己走开；拉腿，她把重心挪到另一只脚上。
- 她的态度按心情：亲近的时候顺着跟；紧张的时候站稳、用力拉时往回拽，拉久了才挣开；困的时候软软地跟。她也会知道你拉了她哪里，下一轮聊天里是事实。
- 什么时候没反应：她睡着；她凑到镜头前；桌宠里她正伸手牵你或牵着时，按她的**手**归牵手，不算拉（身体其他地方照样能拉）。
- 和牵手的区别：牵手是鼠标停在她手边、她伸手、你**点一下**，牵上后手跟着鼠标走；拉她是**按住拖**，她被你拉着，松手就结束。

## 常见问题

- **入口在哪里？** 都在桌宠窗口她身上：摸头是头顶，捏脸是脸颊，喂零食是把图片拖到嘴边，牵手是把鼠标停在她手边，拉她是按住她的手、身体、头或腿拖。设置页里没有对应按钮，也不需要改任何设置。
- **摸不到、捏不到？** 她被隐藏时不响应；移动太慢或太快不算；摸头要来回动，不能只把鼠标放着。
- **拉不动？** 她睡着、凑到镜头前时没反应；牵着手时按手是牵手；要按住拖，只点一下不算。
- **喂不进去？** 要拖单张支持的图片，在嘴边稍停到她张嘴，再松手。
