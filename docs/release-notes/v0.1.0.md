# soft hearts v0.1.0（第一个公开版本）

一个住在桌面上的 MMD 角色，用**你自己的 Claude Code** 和你聊天。只支持 Windows。

## 怎么装

把这句话发给你自己的 Claude Code：

> 请从 https://github.com/LexZeon/soft-hearts 帮我安装并启动 soft hearts，聊天用我自己的 Claude Code 登录。请先介绍能用的功能，偏好可以先用默认值，以后再改。

或者下载源码 ZIP，解压到一个短路径（比如 `C:\soft-hearts`），双击 `start-soft-hearts.cmd`。详见 [START-HERE.md](../../START-HERE.md)。

需要：Windows 10/11、已登录的 Claude Code（用你自己的订阅）。soft hearts 不读取、不保存你的登录凭据。

## 这一版能做什么

**陪你聊天**
- 用你自己的 Claude Code 聊天，一直开着一个聊天进程，回得快。
- 她对你说的话会有即时的小反应（表情、小动作、脸红），然后再开口。
- 她有自己的作息：白天不太困，夜里困意涨得快；关着她的时候算她在休息。
- 可以告诉她怎么叫你，也可以给她起外号。
- 她关心你的事只问一次，不会反复追问；回复不会总用省略号开头。
- 「心情调整员」默认开着：过一两分钟，你 Claude 里的 haiku 会按她的性格和此刻的心情，把她的心情再微调一下（会用你的 Claude 用量，普通的一天约 80 次，有每天上限）。可以在「隐私与设置」里关掉。

**她自己会找你说话**
- 你最近和她聊得多，她就更想主动开口。
- 她说了你没回，她接着说的欲望会大幅降低（间隔拉长，最长 90 分钟）。
- 在设置 →「她主动找你说话」里可以调成"少一点 / 适中 / 多一点"，也可以直接对她说"话少一点"。

**和她一起听、一起看**（都要你自己打开，默认关闭）
- 「和她一起听」：听你电脑里正在放的声音。放歌时她会跟着节奏点头或跳（跳不跳看她的心情；想让她一直跳，在设置 →「轻一点，自然一点」→ 高级里打开「让她一直跟着跳」）。听歌、看剧会记下简短笔记。
- 有人在说话的视频（讲解、采访）：说话内容只在内存里留最近 10 分钟，你问"这视频说了什么"时她答得上来；不写到硬盘。
- 她会自己判断你的话要不要看一眼摄像头、屏幕，或听一下刚才电脑里的声音（只在你打开了对应功能时）：先照常回你，看完再补一句。
- 「和她一起看」：工具栏上的眼睛按钮，一次同时打开「一起听」和屏幕共享，看剧不用记两个开关。开着时你每发一句，她都会看一眼屏幕。画面变化够大时，你 Claude 里的 haiku 会看一眼、记下一两句"这一刻演到哪"（每小时最多 30 次），和听到的话、剧情概要按时间排好；你聊到剧情时，她读这条记录来回答，跟得上正在演的地方。
- 看剧笔记和关键词：看过的画面描述和剧情概要按角色记下来，带上关键词；以后你提到那部剧、那个人，她能按关键词找回来。聊天笔记也会打关键词，找回以前聊过的事更准。
- 屏幕、摄像头共享：发消息时把最新画面交给她。

**其他**
- 喂她图片（最大 50 MB，很大的图会先缩小再看）。
- 语音输入：打开后**按住 T 说话，松开就发送**（先点一下她，让桌宠窗口在最前面）；不按 T 时不收音。默认用本机识别，声音不上传（第一次要下载识别组件）。
- 免费的系统语音朗读她的回复（默认开）。
- 内部通道：你的 Claude Code 可以帮你调她的设置、看她现在怎么样；改动 30 分钟内可以撤回。可以在「隐私与设置」里关掉。
- 任务执行（让她帮你读写某个文件夹里的文件）：默认关闭；写文件和运行命令每次都要你批准。
- 穿透模式默认开着：她周围的透明空白处点得穿，不挡你用别的软件；她本身、工具栏和聊天框照样能点。可以在设置里关掉。
- 预装 Gene 模型和动作；也可以换成你自己的 PMX/PMD。

## 隐私

- 屏幕、摄像头、麦克风、电脑声音都默认关闭，只有你自己打开才用。
- 你的聊天、日记和她对你的了解都存在你自己的电脑上。
- 她对你的了解（用户画像和日记）默认不记录；在设置里打开「允许记录」后才记。之后一直按你最近一次的选择，换角色、重启都一样。
- 「和她一起看」开着时：屏幕的小截图存在你电脑上，30 分钟后自动删除；画面描述、剧情概要和关键词长期存在你电脑上（按角色分开），会交给你 Claude 里的 haiku 处理，用你的 Claude 用量（看画面每小时最多 30 次，概要最多 5 分钟一次）。听到的原话只在内存里。画面里的聊天、账号这类私人内容不会被抄进笔记。忘掉聊天记忆时，看剧笔记一起进回收站，可以找回。
- 源码里没有私人模型、账户或密钥。

## 已知问题

- 偶尔她会把回复前自己"想怎么回"的几句话也显示、读出来；根本的修法在做，下一版带上。
- 心情平静时，她跟着音乐多半只是轻轻点头，不太跳。
- 「和她一起看」开着时每 10 秒截一次屏来判断画面有没有变，占用多少处理器还没在不同电脑上量过；觉得卡可以先关掉。
- 英文：界面有英文，但还有一些地方没翻译；用英文和她聊，她多半会用英文回，偶尔可能有一句被过滤掉。完整的英文版下一版带上。
- 只在 Windows 11 ARM64 上从头装过一遍；x64 电脑还没在全新环境里试过。
- 没有代码签名，Windows 可能会提示"来自网络"的文件；按 [START-HERE.md](../../START-HERE.md) 处理。
- 这是开发预览版，可能有没测到的问题。遇到了欢迎在 Issues 里告诉我们。
