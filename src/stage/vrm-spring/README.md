# VRM 的头发和衣服（舞台部分 · VRM 物理）

I-152 原样载入的第 3 步（2026-11-21）。原样载入的 VRM 按它自己文件里的弹簧骨骼（VRMC_springBone，0.x 的 secondaryAnimation）动起来：头发、大衣下摆、裙子。MMD 模型的物理（`../model-physics.ts`、果冻层）一点不变。记录：docs/claude/2026-11-21-vrm-physics.md。

## 文件

| 文件 | 做什么 |
|---|---|
| `spring-rig.ts` | 从"已载入的模型"（`../model-adapter/vrm.ts` 交来的链、碰撞体、碰撞组）造出要算的东西：链在"下一节不是上一节的子骨"处断开，按父在前排好；1.0 最后一节只当骨尾，0.x 最后一节也摆、骨尾沿骨头 7 cm；人形骨骼上的节不算；名字像胸的链归「胸部弹性」，其余（头发、大衣、裙子、飘带）归「头发物理」；挂在髋或腿下、自己没有腿部碰撞体的链补上她的腿 |
| `body-colliders.ts` | 她的髋、大腿、小腿胶囊：大腿从髋关节到膝、小腿从膝到脚踝、髋横跨两个大腿关节；半径取最里面一层网格（每块网格分开量，取最小的），所以部分蒙皮到腿上的大衣不会把腿量得和大衣一样粗；主要挂在弹簧骨上的网格（裙子、下摆）不量 |
| `vrm-springs.ts` | 每帧的解算 `VrmSpringPhysics`：规范的一步（拖拽、刚度、重力、长度、碰撞体）换成和步长无关的速率，固定小步（省电 1/60、标准 1/120、细致 1/240 秒）；一帧里每个小步看到的身体是上一帧到这一帧之间的位置，所以 30 帧和 60 帧摆得一样 |

## 接在哪里

- Unbound 的标准身体（`src/unbound/model/standard-body.ts`）在 VRM 静止时造它（`VrmSpringPhysics.of`），`present(physicsDelta)` 先把姿势换到 VRM 自己的骨头上，再算弹簧。窗口模式经 `window-body.ts` 传帧的真实时长；全屏经 `src/unbound/main.ts` 传 `raw`。
- 开关：窗口模式经 `src/unbound/window-mode/window-physics.ts`（同一份「头发物理」「胸部弹性」「物理质量」，藏起来暂停，控制窗口的预览里不算，不为标准骨架载入 Ammo）；全屏经 `src/unbound/figure-physics.ts`（场景的设置和档位上限，`StandardBody.ofMesh` 找到她的弹簧）。
- 旧舞台里的 VRM 不接：那里 VRM 只是站着显示、不动，弹簧没有可跟的动作。

## 守的规矩

- **不瞬移**（R29）：她被放到别处（一帧移动超过 0.6 米或转过 60°）、或者隔了一段时间才来下一帧（藏起来、卡顿），整条链跟着根一起搬，形状不变，不从原处甩过来；骨尾绕它的根转得再快也不超过 `MAX_SPIN`；开关打开或关上都在 0.4 秒里缓进缓出（起止速度为 0）；刚开始时先在看不见的小步里垂好再淡入。
- **碰撞体**：文件自己的按规范硬推；我们补的腿部胶囊外面多一层 4 cm 的缓冲，靠近时把相对速度刹到 0，再由硬表面兜底，而且不把骨尾推得比它静止时离腿更远。
- **睡眠**：一条链静止 0.6 秒就不算，根或碰撞体一动就从显示的姿势醒来。
- **强度**：效果强度是"她的动作有多少让骨尾落后"（1 = 文件的物理原样，0 = 跟着身体硬走）；重力、刚度、碰撞照旧，所以调低不会让下摆穿进腿。
- 测试：`tests/vrm-springs.test.ts`（读法、补的碰撞体、各道门）、`tests/vrm-springs-loop.test.ts`（窗口真实帧循环 60 / 30 fps，修前修后的数字，`R29_REPORT=1` 打印）；变异 `scripts/dev/mutations/stage.json` 的 VS1–VS6、`unbound.json` 的 VS-U1–U4。
- 只用 three 本体，不加依赖；模型文件一个字节都不改。
