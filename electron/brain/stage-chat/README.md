# 台上的聊天：都听得见、都记、谁接话由她们定（I-209 第 4 步）

记录：`docs/claude/2026-11-24-i209-step4.md`。全屏里几位同时在场时（「三人同框（Beta）」开着、台上两位以上）才起作用；只有一位时这里什么都不做。

| 文件 | 管什么 |
|---|---|
| `hearing.ts` | 聊天记忆告诉"谁说了一句"（`MemoryStore.onStageLine`）：台上每位别人各记一份（`appendStageLine`，带着是谁说的、你的话对谁说的），同一句只一份；听见的那份不再传（编号以 `heard-` 开头） |
| `chime-in.ts` | 接话的一轮轮：她说完一句，别人各问一次 haiku，第一个说接的先说，其余作废；一直接下去，没人接就停；你开始说话、别人开口都会让正在进行的这一轮作废。开关「她们都能接话」关着时一次都不问 |
| `facts.ts` | 给她的事实（谁在台上、刚才谁说了什么、你之后台上说了几句、你多久没说话、你是不是在忙或不在），判断和她那句的提示词。只写事实，不写规矩（`tests/i209-chime-in.test.ts` 守着） |
| `turns.ts` | 她的两次调用：判断；她那句（等空、进她的气泡、她的声音、只记一次、念完交出发言权）。作废的不显示不记。台上的声音（`docs/claude/2026-11-24-i209-stage-voice.md`）：等台上真的安静（没有在说、没有在响，保持 0.6 秒）才出来，有人在说就一直等（上限 3 分钟）；气泡画出来以后才交给陪伴窗口用她的卡念；你开始说话时她正在念的那句停下；每种结束一个词（said / quiet / dropped / failed / unreadable / busy / not-shown） |
| `model.ts` | 大脑接口：两次单次无工具调用（判断 haiku，她那句用聊天模型）。只有这里知道 Claude 的参数 |
| `perceive.ts` | 感知只做一次：台上别人读同一份屏幕描述 |

接线：`electron/wiring/brain-stage-chat-wiring.ts`。体验记录：每次判断、每次接话一行 `chime-in`（谁、问还是说、结果、毫秒；不含文字）。
