# MPI EMBM

Source: https://figshare.com/articles/dataset/MPI_EMBM_Database_Mocap_Files/1220428
DOI: 10.6084/m9.figshare.1220428.v1
The official Figshare API declares CC BY 4.0.

The official 50,099,276-byte archive matches its published MD5 but is truncated and has no ZIP central directory. Only complete CRC-verified BVH members were recovered; partial members are excluded. These five excerpts are from intact files. The source's advertised total was not fully recoverable.
